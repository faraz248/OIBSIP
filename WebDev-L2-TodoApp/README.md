# WebDev-L2-TodoApp

## Task 3: To-Do Web App

This is my third task for the Oasis Infobyte Web Development Internship.

### Features
- Can add new tasks.
- Tasks are divided into "Pending" and "Completed".
- Shows a message when there are no tasks in a list.
- Can edit tasks by clicking on the edit button.
- Uses localStorage so the tasks are saved even if you refresh the page.

### Tech Stack
- HTML
- CSS
- JavaScript

To run, open `index.html` in your browser.
