# WebDev-L2-TributePage

## Task 2: Tribute Page

This is my second task for the Oasis Infobyte Web Development Internship.

### About
I created a tribute page for Dr. A.P.J. Abdul Kalam. It includes a short biography, a timeline of his life, and some quotes.

### Features
- Used semantic HTML tags.
- Added two different background colors as requested.
- Used two different font styles (Merriweather and Open Sans) from Google Fonts.
- The page is responsive on mobile and desktop.

### Tech Stack

- CSS

To view the page, open `index.html` in your browser.
