# WebDev-L2-AuthSystem

## Task 4: Login Authentication System

This is my fourth task for the Oasis Infobyte Web Development Internship.

### Features
- Made a simple login and registration system.
- Used `localStorage` to save user data so no database is needed.
- Passwords must be at least 8 characters long and have a number.
- You cannot register twice with the same email.
- The password is encrypted before saving.
- The dashboard page redirects you to login if you are not logged in.
- Logout button works and clears the session.

### Tech Stack
- HTML
- CSS
- JavaScript

### How to Run
1. Open `index.html` in your browser.
2. Go to Register and create an account.
3. Login using your new account.
4. You will see the dashboard page.
5. Click Logout to exit.
